①課題名

PHPアンケートアプリ（プログラミング言語調査ver.）
②課題内容（どんな作品か）

G'sACADEMYの受講生を対象にしたプログラミング言語に関するアンケートアプリ
好きな言語・経験年数・転職に有利な言語など複数の質問項目を実装
回答をテキストファイルに保存し、結果一覧を表示する仕組みをPHPで実装
XSS対策（htmlspecialchars）によるセキュリティ対策を実装

③アプリのデプロイURL

http://japantokyosakura.sakura.ne.jp/index.php
④アプリのログイン用IDまたはPassword（ある場合）

なし

⑤工夫した点・こだわった点

ピンク系のかわいいデザインで回答しやすいUIにした
プルダウンに加えて自由記述欄を追加して柔軟に回答できるようにした
各質問に理由記載欄を追加してより深い回答が得られるようにした
G's受講生が興味を持てる質問項目（お金になる言語・転職に有利な言語など）を設計した

⑥難しかった点・次回トライしたいこと

さくらサーバーへのデプロイ（FTP・PHP設定・DB接続など）
次回はPythonでアンケート結果を集計してExcelレポートを自動生成したい
Chart.jsでグラフ表示機能を追加したい

⑦フリー項目

【感想】サーバー・DB・FTPなど初めて触れる技術が多く大変だったが、バックエンドの仕組みが少しずつ理解できてきた。ローカル環境（XAMPP）とサーバー環境の違いや、テキストファイルとMySQLの使い分けなど、実際に手を動かすことで学べることが多かった。
